# Malaysia Vehicle Registration

Open this folder in VS Code. It must be the folder that contains `package.json`, `public`, and `src`.

In the VS Code terminal:

```powershell
npm install
npm start
```

`npm install` downloads the React packages. Run it once. `npm start` starts the app. When it says compiled successfully, open http://localhost:3000.

Node.js must be installed. If the terminal says `npm` is not recognized, install Node.js and open the folder again.
